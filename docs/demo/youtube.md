## Title

Sentinel v2 — appealable rulings, frozen mandates and graduated slashing for AI agents on GenLayer

## Description

Sentinel puts a bond behind what an AI agent promises. An operator registers an agent's wallet under numbered clauses with a severity each; anyone can challenge one of its transactions; GenLayer validators each fetch the transaction and must agree on a verdict. Rulings stay provisional for an hour and can be appealed once; mandate edits never reach back; code computes every slash. Recorded from the live site and the GenLayer Studio Dev explorer; every number spoken is a contract read taken just before recording.
