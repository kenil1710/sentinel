# Screenshots

Captured from the live deployment at https://sentinel-tau-ashen.vercel.app with
headless Chromium, full-page, animations frozen so repeat captures are
identical.

- `desktop/` — 1440×900 viewport, 2× device pixel ratio
- `mobile/`  — 390×844 viewport, 3× device pixel ratio, touch enabled

Eleven pages each: landing, agents, patrol, leaderboard, analytics, docs,
register, two agent details — one on duty and one caught and deactivated — and
two challenge pages, one VIOLATION and one COMPLIANT, so both ends of the
verdict range are shown rather than only the dramatic one.

The figures visible in these images are live contract state at capture time and
will not match the contract later: the patrol keeps filing and settling. Read
`get_stats` for current numbers.
